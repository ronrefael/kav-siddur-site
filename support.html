Kav Siddur Support

Official support page for the Kav Siddur app.

How To Reach Us

  • Report a problem or ask a question: issue tracker (no account data is required to read existing answers; filing an issue requires a free GitHub account)

What To Include

When reporting a problem, please include:

  • device model
  • iOS or Android version
  • app version/build number
  • the service or screen you were using
  • whether location permission was granted or denied
  • screenshots if available

Privacy Questions

For privacy or data-practice questions, see the privacy policy or open an issue on the tracker above.

Scope Of Public Release Support

Public release support covers:

  • prayer reader issues
  • Times/zmanim issues
  • Tehillim progress issues
  • settings and display issues

The public release does not include account recovery, community moderation, or cloud-sync support because those features are not part of the launch scope.
